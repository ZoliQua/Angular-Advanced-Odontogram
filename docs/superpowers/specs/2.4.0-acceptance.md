actual command run during this task (Phase 9 Task 2, 2026-08-19), not an
assertion. All commands were run from the worktree root

`app-version.ts`), the CHANGELOG `[2.4.0]` entry + compare-link update, the
13 README badge/lockstep-sentence edits, and this evidence sheet.
