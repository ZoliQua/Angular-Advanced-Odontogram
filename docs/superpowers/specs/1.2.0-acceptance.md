**FESM growth vs 1.1.0 — measured, and why.** Same 15-file shape as 1.1.0
(the 4 font chunks + loader unchanged in count and near-identical in size —
`notoArabic`/`notoSC`/`roboto`/`loader` all within a few hundred bytes of
their 1.1.0 sizes, confirming the font modules themselves didn't change
this release). The **main** FESM grew `2.5MB → 3.9MB` (+1.4MB) and its
sourcemap `3.4MB → 5.0MB`; package size `2.6MB → 3.3MB`; unpacked
`8.3MB → 11.4MB`. Two concrete, measured sources, not general bloat:

1. **Measured-anatomy SVGs (dominant factor).** Task 1's `gen:assets`
   extension folded 13 new `measured/*.svg` tooth-anatomy files into the
   generated SVG-string module:
   `projects/angular-advanced-odontogram/src/lib/core/generated/teeth-svgs.ts`
   is now **1.6MB** (`du -sh` confirmed), up from ~435KB at 1.1.0 (per Task
   5's report) — a **+1.2MB** literal-string payload increase baked
   straight into the library's single FESM output (this module has no
   dynamic-import boundary, unlike the PDF fonts), which alone accounts for
   the large majority of the main-FESM growth.
2. **Composable UI surface/card components.** The exported
   `OdontogramUiService` (813-line transcription of `OdontogramContext.tsx`),
   `engineState()`, 4 surfaces, and 7 declarative control cards (Tasks 2-3)
   are new compiled Angular component code that didn't exist at 1.1.0 (the
   1.1.0 shell held the equivalent logic as private, non-exported internals
   of `OdontogramShellComponent` — now it's public, standalone, separately
   compiled component code, plus the new `CreditsModalComponent` and the
   `[aaoForceValue]`/`[aaoForceChecked]` directives), a smaller but real
   contributor to the delta.

README, LICENSE, `styles.css`, `package.json`, and the typings file remain
present as before (typings grew `245.7kB → 351.2kB`, tracking the new
public exports) — no dev/test artifacts leaked into the tarball; total file
count unchanged at 15.
