## (c) Test-seam export fix — `ODONTOGRAM_SET_TOOTH_ANATOMY`

**The finding (Task-4 review, controller ruling):** the DI token used to
force a failed lazy-chunk load in a spec lived in `odontogram-ui.service.ts`,
whose wildcard re-export from `public-api.ts` leaked it into the public
surface, while its own comment claimed it was "NOT exported".

**The fix:** the token moved to
`projects/angular-advanced-odontogram/src/lib/components/odontogram-set-tooth-anatomy.ts`
(a file `public-api.ts` does not re-export — the same arrangement as
`odontogram-i18n-loader.ts` / `ODONTOGRAM_I18N_LOADER`), the comment now says
so, and the two now-unused imports in `odontogram-ui.service.ts` were
removed. `ODONTOGRAM_ENGINE_LIFECYCLE` is deliberately still public (hosts
override it).

`npm run build:styles`, `npx ng build angular-advanced-odontogram`):
