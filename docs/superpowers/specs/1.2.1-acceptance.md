Task 2's ledger entry flagged `CONTRIBUTING.md` as stale — written when the
project had only 2 full READMEs (EN + HU) and still promised per-contributor

current reality; everything else in the file is untouched:

   Credits popup and in the README's Credits section" → "contributions are
   acknowledged in the project's commit history" (matches the trimmed
   modal/README — no contributor names anywhere in the credited surfaces

   full-length READMEs (... `README.md` and its Hungarian mirror,
   `lang/README-hu.md`) rather than twelve" → describes the now-complete
   12-language `lang/` set, with `lang/README-en.md` named as the canonical
   reference the others mirror (matching the Global Constraints' own
   framing of T2 as canonical for T3-T5).
3. **"Documentation" section** — "Update `README.md` and
   `lang/README-hu.md` together" → "Update `README.md` and
   `lang/README-en.md` (the canonical full documentation) together ...; the
   other eleven `lang/` translations should follow on the next
   documentation pass" (keeps the practical guidance — don't require every
   PR to touch 12 files — while no longer citing HU as the only mirror).
4. **"Credit" section** — "you are added to the Credits popup in the app
   and to the Credits section of the README" → describes what the credited
   surfaces actually list now (creator, original project, built-with) and
   that contributions are acknowledged via commit history instead.
