Add to `projects/angular-advanced-odontogram/src/lib/lazy-loading.guard.spec.ts` a new `describe`

```ts
describe("Angular shell: the language pickers cover the whole registry", () => {
  it("the topbar and Settings pickers both offer every language in LANGUAGES, in registry order", () => {
    // A hand-written picker list is how a language gets wired into the core
    // and still never reaches the UI. Both lists are checked against the
    // registry, not against each other, and ORDER matters: upstream's two
    // LANGUAGE_OPTIONS arrays are in LANGUAGES order and this port copies
    // them verbatim.
    for (const [name, options] of [
      ["topbar", TOPBAR_LANGUAGE_OPTIONS],
      ["settings", SETTINGS_LANGUAGE_OPTIONS],
    ] as const) {
      expect(options.map((o) => o.value), name).toEqual([...LANGUAGES]);
      expect(options.map((o) => o.labelKey), name).toEqual(LANGUAGES.map((l) => `language.${l}`));
    }
  });

  it("every picker label key resolves in the fallback language", () => {
    // A label key with no string shows the raw key in the menu.
    for (const lang of LANGUAGES) {
      expect(t(`language.${lang}`), lang).not.toBe(`language.${lang}`);
    }
  });
});
```

Both `LANGUAGE_OPTIONS` arrays are currently module-private `const`s. Export them from their
components (`export const LANGUAGE_OPTIONS`) and import them in the spec under the aliases above —
exporting a constant the spec asserts on is preferable to re-deriving the list from the rendered DOM,
which would test the template instead of the list. If an existing spec already reaches these lists
through the DOM, keep that spec as it is and add these as the registry-level guards.

The second guard — the 3.2 MB question — goes in the same file, next to the existing
`translations`/`measured` static-import scans, reusing their `sourceFiles` + `staticImportSpecifiers`
helpers:

```ts
it("nothing outside lib/core/ statically imports an embedded PDF font (incl. public-api.ts)", () => {
  // notoKR.ts alone is 3.2 MB of base64. core/fonts/loader.ts reaches every
  // font through a dynamic import so each stays its own chunk, loaded only
  // when a PDF is exported in that language; one static import anywhere above
  // lib/core/ undoes that for every consumer of this package.
  const offenders: string[] = [];
  for (const file of sourceFiles(SRC_ROOT, "")) {
    const rel = path.relative(SRC_ROOT, file);
    for (const spec of staticImportSpecifiers(readFileSync(file, "utf8"))) {
```
